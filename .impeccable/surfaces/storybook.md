# Kraft UI component explorer

Mode: Read, with interactive component exploration.

Build path: code-first, preserving the established material vocabulary.

First viewport: a desk composition showing thick cardboard supporting straight paper sheets and printed sticker marks. A responsive heading introduces the material system; the functional keep action visibly changes its label and announces a status. Foundations and API documentation remain one navigation step away.

Signature interaction: buttons travel down and right to meet their cut edge. They never tilt. A saved idea stays pressed through aria-pressed state. Reduced motion removes transitions while retaining visible state.

Layout: a wide board and narrow margin note on desktop, a single reading column on mobile. Local fonts demonstrate the application-owned typography contract.
