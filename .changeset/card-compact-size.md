`Card` and `CardAddTile` gain `size="compact"`, which drops the `10rem` base height so the card or tile is as tall as its content. Use it for cards that hold a line or two, such as cards on a board, in a list, or in a thread. The default is unchanged, and `--kraft-card-min-height` still sets the base height of default cards. Adds the `CardSize` type.
